# PeopleStrong — Campaign Intelligence Agent

Prototype mockup for the AI-powered campaign performance monitoring, creative generation, and budget optimization agent.

## Stack
- React 18 + Vite 5

## Run locally
```bash
npm install
npm run dev
```

## Deploy
```bash
vercel
```

## Tabs
- **Daily Digest** — KPIs, agent actions, budget pacing
- **Campaigns** — Performance table with expandable agent insights
- **Creative Lab** — AI-generated ad variants for human review
- **Flow** — End-to-end agent process (Ingest → Analyze → Act → Report)
